
# MS-4019-Executive Persona Agents

# Applied Exercise – Executive Leadership Workflows with Microsoft 365 Copilot Agents

## Learning Objectives

In this exercise, you will use Microsoft 365 Copilot prebuilt agents and a custom agent to support executive leadership workflows such as strategic planning, operational analysis, and executive communications.

By completing these activities, you will learn how to:

- Use the Researcher agent to analyze organizational information
- Use the Analyst agent to generate operational and business insights
- Generate executive-ready summaries and strategic briefings
- Create a custom Executive Briefing Agent in Microsoft 365 Copilot
- Apply retrieval-based AI experiences to leadership scenarios

---

# Prerequisites

Before starting this exercise, ensure you have access to:

- Microsoft 365 Copilot
- Researcher agent
- Analyst agent
- Create Agent in Microsoft 365 Copilot

Sample organizational content can include:

- [Board Deck]
- [Executive Summary]
- [Strategy Tracker.xlsx]
- [Investor Presentation.pdf]
- [Leadership Meeting Notes.docx]

# Exercise 1 — Analyze Strategic Context with Researcher

Use the Researcher agent to identify key business trends impacting the organization.

## Steps

1. Open Microsoft 365 Copilot Chat.
2. Expand the **Agents** menu.
3. Select **Researcher**.
4. Enter the following prompt.

## Prompt

```text
Summarize the key business trends impacting our organization this quarter.
```

## Expected Outcome

Researcher generates a summary of strategic trends, organizational priorities, and business themes identified across available business data.

# Exercise 6 — Create an Executive Briefing Agent

Create a custom agent that generates leadership-ready summaries and strategic briefings using organizational knowledge sources.

## Steps

1. Open Microsoft Copilot Studio.
2. Select **Create agent**.
3. In the **Describe** tab, enter the following instructions.

## Agent Instructions

```text
You are an Executive Briefing Agent that helps leadership teams generate concise strategic summaries, executive briefings, and decision-support insights using organizational data sources.

Provide responses that are:
- Clear and concise
- Executive-focused
- Action-oriented
- Grounded in organizational content

When possible:
- Reference recent documents, meetings, and communications
- Summarize key risks and opportunities
- Highlight business impact and strategic relevance
```

4. Select the **Configure** tab.
5. Add one or more knowledge sources such as:
   - Emails
   - Teams chats
   - Meeting notes
   - SharePoint documents

6. Use the **Test** pane to validate the agent.
7. Refine the instructions as needed.
8. Select **Create** to publish the agent.
